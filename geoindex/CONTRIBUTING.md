# Contributing to GeoIndex

Thank you for your interest in contributing to GeoIndex.

Our goal is to build reliable, readable, and scientifically reproducible software for the Earth Observation community.

## Development Principles

- Prioritize code readability.
- Write clear documentation.
- Add tests for new functionality.
- Follow PEP 8.
- Use meaningful variable names.
- Keep functions focused on one task.

## Scientific Integrity

GeoIndex is developed with scientific integrity as a core principle.

- Never copy code from other software projects.
- Implement algorithms based on scientific publications and official specifications.
- Cite original scientific references where appropriate.
- Verify results before adding new features.

## Pull Requests

Every contribution should:

- Include documentation.
- Pass all tests.
- Maintain backward compatibility when possible.
